# TaskFlow · 任务管理看板

> Linear 风格深色主题的任务管理看板应用，支持拖拽排序、优先级、标签、截止日期与本地持久化。

## 功能特性

- **四列看板**：待办 / 进行中 / 审核中 / 已完成，卡片支持跨列拖拽与列内排序
- **任务管理**：新建、编辑、删除任务，含标题、描述、优先级（紧急/高/中/低）、截止日期、标签
- **本地持久化**：基于 localStorage 自动保存，刷新页面数据不丢失
- **搜索与筛选**：按标题/描述/标签搜索，侧栏按优先级与逾期状态筛选
- **统计面板**：实时展示任务总数与完成率进度条
- **快捷键**：`⌘N` 新建任务 · `⌘K` 搜索 · `Esc` 关闭弹窗

## 技术栈

- 纯 HTML / CSS / JavaScript（无框架依赖）
- Python `http.server` 作为本地开发服务器
- Inter 字体（Google Fonts）

## 快速启动

```bash
python -m http.server 8080
```

浏览器访问 http://localhost:8080

## 项目结构

```
├── index.html   # 主页面
├── styles.css   # 样式（Linear 风格深色主题）
├── app.js       # 交互逻辑（拖拽/增删改/持久化）
└── README.md
```

## 设计亮点

采用 Linear 风格深色主题，紫色（#6E56CF）为主色调，配合优先级色彩系统。卡片左侧优先级色条、玻璃态弹窗、微交互动画，营造专注高效的任务管理体验。
